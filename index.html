Image Subject Detection Application

The goal of the project was to explore how machine learning can be integrated into a web application using JavaScript while creating a simple and user-friendly interface.

An interactive web application that uses artificial intelligence to identify the subject of an uploaded image. The application uses Google's TensorFlow.js library and the MobileNet pre-trained machine learning model to analyze images directly in the browser and return a predicted subject along with a confidence percentage.

Technologies Used

HTML, CSS, JavaScript, TensorFlow.js, MobileNet

Features

  • AI Image Recognition: Uses the MobileNet model to identify objects and subjects within uploaded images.
  • Image Upload: Allows users to select an image from their device using a file browser.
  • Drag-and-Drop Functionality: Users can drag an image directly into the designated drop zone.
  • Image Preview: Displays the selected image before presenting the classification results.
  • Confidence Score: Shows the model's predicted subject and its confidence level as a percentage.
  • Loading and Status Messages: Provides feedback while the AI model loads and analyzes an image.

Development Process

I used HTML to structure the application, creating an image upload area, preview element, and results section. CSS was used to style the interface, including the dashed drag-and-drop area, layout, colors, and visual feedback.

JavaScript handled the application's functionality. I implemented an asynchronous function to load the MobileNet model when the page opens. Once the model is ready, users can upload or drag and drop an image into the application. The selected image is displayed using a temporary object URL, and an event listener triggers the image analysis once it has loaded.

The MobileNet model then classifies the image and returns its most likely subject and associated confidence score. I also included checks to ensure the model is ready and an image has been selected before attempting classification.

Key Skills Demonstrated

  • Integrating a pre-trained machine learning model into a web application.
  • Working with TensorFlow.js and the MobileNet image classification model.
  • Writing asynchronous JavaScript functions using async and await.
  • Handling file uploads and browser events.
  • Implementing drag-and-drop functionality.
  • Dynamically updating webpage content through the DOM.
  • Styling interactive web elements with CSS.

Generative Art: Composition Creator

Combining programming logic with creative experimentation to produce unique, algorithmically generated visual compositions.

Composition Creator is an interactive generative art project developed using Processing (Java). It explores the relationship between randomness, color, shape, and visual composition to create unique abstract artwork.

Using algorithmic techniques, the program generates layered compositions of geometric shapes, including circles, ellipses, and rounded rectangles. Each shape is assigned randomized colors, sizes, transparency levels, and positions, resulting in an evolving visual composition. A random selection from 4,495 emojis from openmoji.org are part of the layered composition with random positioning and transparency.

The project also incorporates external image assets, allowing imported images to become part of the generated artwork through randomized placement and color tinting. Users can pause the animation and capture individual compositions, which are automatically saved as timestamped PNG files.

Technologies and Tools

  • Processing (Java)
  • Java programming concepts
  • OpenMoji (CC BY-SA 4.0 licensed image assets)
  • Processing graphics and image libraries
