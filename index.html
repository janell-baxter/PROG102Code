Code Trivia Interactive Web Application

Designed and developed an interactive trivia application focused on computer science history and technology. The application features a series of expandable questions that reveal answers when clicked, creating a simple and engaging user experience.

Try it: Code Trivia

Using HTML, CSS, JavaScript, and jQuery, I implemented interactive accordion-style functionality with smooth slide animations and dynamic styling to provide visual feedback when users interact with questions.

The project also features custom CSS styling, a responsive-centered layout, a soft gradient background, hover effects, and Google Fonts typography to create a clean and approachable interface.

Technologies Used: HTML5, CSS3, JavaScript, jQuery 3.7.1, Google Fonts.

Key Skills Demonstrated:

  • Front-End Web Development
  • Semantic HTML Structure
  • CSS Styling and Layout Design
  • JavaScript DOM Manipulation
  • jQuery Event Handling
  • Interactive UI Development
  • Accordion Functionality
  • Animation and Transition Effects
  • User Interaction and Visual Feedback
  • Third-Party Library Integration
